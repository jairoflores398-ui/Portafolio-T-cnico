# Portafolio técnico — Jairo Flores Araya

Portafolio personal y profesional desarrollado como una landing page estática para presentar proyectos, habilidades técnicas, experiencia y datos de contacto de Jairo Flores Araya.

## Descripción

Este proyecto consiste en una página web personal diseñada para:

- Presentar una identidad profesional clara.
- Mostrar proyectos desarrollados durante la formación.
- Destacar tecnologías y capacidades técnicas.
- Facilitar contacto directo con el autor.
- Servir como una carta de presentación digital para oportunidades laborales o académicas.

La página está construida con HTML y CSS puro, sin dependencias externas de compilación ni frameworks, lo que facilita su uso, mantenimiento y despliegue.

## Características

- Diseño responsive y limpio.
- Estética moderna con enfoque técnico.
- Sección de presentación personal.
- Sección de proyectos con enlaces a repositorios y demos.
- Caso de estudio con explicación del proceso de desarrollo.
- Modo claro y oscuro basado en preferencias del sistema.
- Footer con información de contacto.
- Navegación interna por secciones.

## Stack tecnológico

- HTML5
- CSS3
- JavaScript (mínimo, solo en la estructura necesaria)
- Fuentes externas de Google Fonts
- Compatibilidad con navegadores modernos

## Requisitos

Para visualizar la página solo necesitas:

- Un navegador moderno (Chrome, Edge, Firefox, Brave, Safari).
- Un editor de texto o IDE si quieres modificar el contenido.
- Opcionalmente, un servidor local para una vista más realista.

## Cómo ejecutar

### Opción 1: abrir directamente

1. Abre el archivo `portafolio-jairo-flores.html` en tu navegador.
2. La página se renderizará directamente sin necesidad de instalar dependencias.

### Opción 2: servidor local

Desde la raíz del proyecto, puedes ejecutar:

```bash
python -m http.server 8000
```

Luego abre en el navegador:

```text
http://localhost:8000/
```

> Si usas Windows y Python no está en PATH, puedes instalarlo o usar un servidor local del editor/IDE que prefieras.

## Personalización

Para adaptar esta página a otra persona o proyecto, puedes editar los siguientes puntos dentro del archivo HTML:

### 1. Datos personales
Busca y modifica:

- Nombre
- Rol profesional
- Ubicación
- Correo electrónico
- Teléfono
- GitHub
- Enlaces a proyectos

### 2. Proyectos
En la sección de proyectos puedes cambiar:

- Título del proyecto
- Descripción
- Tecnologías empleadas
- Enlaces a código y demo
- Información de impacto o resultados

### 3. Caso de estudio
Edita el bloque relacionado con la experiencia técnica más relevante para reflejar proyectos, decisiones de diseño o aprendizajes específicos.

### 4. Estilos visuales
Los colores, tipografías y espaciados se definen en `assets/css/styles.css`. Puedes cambiar:

- Paleta de colores
- Fuentes
- Bordes y radio
- Espaciado
- Diseño responsive

## Buenas prácticas aplicadas

- Separación clara entre estructura, contenido y estilos.
- Uso de semántica HTML correcta (`header`, `main`, `section`, `footer`, etc.).
- Accesibilidad básica: contrastes, encabezados entendibles y enlaces descriptivos.
- Diseño centrado en contenido y legibilidad.
- Sin dependencias pesadas ni complejidad innecesaria.
- Estructura simple para facilitar mantenimiento.
